`draft: true` 가 있으면 사이트에 나오지 않는다. 이 파일은 새 글을 쓸 때 복사해서 쓰는 견본이다.

맨 위 `---` 사이가 글의 정보다. `title` 과 `date` 는 필수, `draft` 는 없으면 공개된다.

강조는 **볼드** 하나만 쓴다. *기울임*을 써도 볼드로 나온다. 그 외 장식은 없다.

## 소제목

소제목도 본문과 같은 크기에 볼드만 붙는다. 크게 튀지 않는다.

목록은 이렇게 쓴다.

- 첫째
- 둘째
- 셋째

번호가 필요하면,

1. 하나
2. 둘

인용은 이렇게 나온다.

> 왼쪽에 얇은 선이 붙고 글자가 흐려진다.

문장 안의 코드는 `npm run dev` 처럼 쓰고, 여러 줄은 이렇게 쓴다.

```bash
git add -A
git commit -m "새 글"
git push
```

[링크](https://example.com)는 밑줄로 표시된다.
